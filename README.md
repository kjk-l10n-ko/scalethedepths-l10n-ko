## 설정 방법

설치 후 게임을 실행하고 `설정 > 게임플레이 > 언어`에서 **한국어**를 선택함. 한 번 선택하면 설정이 저장되어 이후에는 한국어로 시작함.

## 패치 내용

* 게임 UI·스토리·인게임 대사 3,712개 문자열 번역
* 픽셀 폰트 Galmuri11 Bold 적용 (영문·숫자 포함 폰트 통일)
* 게임에 한국어 로케일이 없어 일본어 슬롯을 한국어로 대체함. 언어 목록의 다른 언어 이름도 한국어로 표기됨.
* 타이틀 로고와 퍼블리셔 로고는 그림 파일이라 원문 그대로 유지됨. 크레딧의 사람 이름도 라틴 문자 그대로 둠.

게임 파일은 포함되어 있지 않으며, 사용자의 원본 번들에 변경분만 적용함. 원본 파일은 게임 폴더의 `kor_bak` 폴더에 백업됨.
